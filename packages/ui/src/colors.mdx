# Colors

## セマンティックカラー

部品の色には、用途で名付けたセマンティックカラーを使います。値は `theme.css` で
定義していて、`background` などは `prefers-color-scheme` でライトとダークが切り替わります。
この見本は閲覧している環境のモードの値で表示されます。
