# Colors

## 意味で名付けた色

部品の色は、用途で名付けた変数を使います。値は `prefers-color-scheme` で
ライトとダークが切り替わるため、`bg-surface text-text border-border` のように
1つのクラスを書くだけで両モードに対応できます（`dark:` は書きません）。

この見本は閲覧している環境のモードの値で表示されます。

文字と地の組み合わせ（`text` / `text-muted` / `accent` / 状態色 × `surface` 3種、
`on-accent` × `accent`、`on-brand` × `brand`、白 × `live`）は、両モードで
コントラスト比 4.5:1 以上になることを `colors.test.ts` で確認しています。

`Primary` / `Secondary` は移行が終わるまで残し、移行後に削除します。
