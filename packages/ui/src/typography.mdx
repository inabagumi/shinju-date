# Typography

文字サイズは、サイズと行間を組にした6段階のクラスで指定します。値は `theme.css` で定義しています。
役割ごとのクラスの組み合わせは `docs/design-guidelines.md` を参照してください。

欧文は Lato、日本語は端末のフォントです。日本語のウェブフォントは、表示の遅れやレイアウトシフトを避けるために使いません。
