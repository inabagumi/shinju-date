# Radius and Shadow

角丸と影は、用途の名前を付けたクラスで指定します。値は `theme.css` で定義しています。
使い分けは `docs/design-guidelines.md` を参照してください。

## 影

影は重なるものだけに使います。通常の部品には影を付けず、余白と `border` で区切ります。

</div>
